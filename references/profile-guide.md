# 公司资料填报与零幻觉边界

## 零、企查查是主渠道，不是可选项

公司事实**先查企查查**，拿企查查的数据填 `company_profile.json`。取证规范见 `references/qcc-sourcing.md`。

企查查管**"有没有"**，但**"算不算"**要人工甄别。三条：

| 甄别 | 说什么 | 典型翻车 |
| --- | --- | --- |
| **相关性** | 查到 N 条 ≠ 得 N 条的分，要逐个看名称是否落在招标限定领域 | 招标要"虚拟仿真相关软著"，查到 23 个软著但相关的为 0 |
| **去重** | "中选候选人公示" 和 "结果公告" 是同一个项目 | 10 条中标记录里有 2 条属同一项目 |
| **主体一致** | 权属人必须是受评公司本身 | 母公司的证书、兄弟公司的业绩不算 |

企查查查不到的（平台数据、合同关键页、等保备案、承诺函意愿、政府采购失信名单）→ 找公司要或上官网查 → 要不到 → `UNKNOWN`。

## 一、资料只能来自三个地方

1. **企查查**（`source=QCC`）—— 主渠道；
2. 官网查询截图（`source=WEB`）—— 信用中国、中国政府采购网等；
3. `company_profile.json` 里公司提供的原件（`source=USER`）。

**除此之外一律不得作为判定依据。** 尤其是：
- 不得用常识推断（"做这行的一般都有 ISO9001"→ 不许）；
- 不得用同行业类比（"同行都有这个证，它应该也有"→ 不许）；
- 不得用公司自己的口头陈述代替材料（"我们大概有 300 多门课"→ 没有截图就是 `UNKNOWN`）；
- 不得用网络搜索结果补充公司资质（搜到的宣传页不能当证书用）；
- **不得把"企查查查到 23 个软著"直接当成"23 个都符合招标限定领域"**。

## 二、证据编号是硬约束

- 所有材料进 `evidence_index`，编号 `EV-001` 递增。
- 每条证据必须标 `source`（`QCC` / `WEB` / `USER`）；`source=QCC` 必须带 `tool` 与 `fetched_at`。由 R11 校验。
- 逐条判定的 `evidence` 数组**只能**填 `evidence_index` 里存在的编号。由 R8 校验。
- 判 `PASS` 的条目，`evidence` **不得为空**。由 R12 校验。
- 一条判定没有任何证据编号，却判 `PASS` → 属于幻觉，必须改成 `UNKNOWN` 并写明缺什么。

## 三、三类"看起来能算、其实不能算"的材料

| 情况 | 怎么判 |
| --- | --- |
| 证书权属人是关联公司 / 母公司 / 子公司 | `UNKNOWN` 或 `FAIL`（看原文是否认可），**不得默认算数**，登记 issue |
| 业绩合同缺盖章页或签订时间 | `UNKNOWN`，missing 写"缺合同关键页 X" |
| 截图没有平台名称 / 没有后台数据 / 是 PPT 或 demo | 按原文要求判。凡写"应用真实运行系统平台演示，用 PPT/word/图片/demo 演示的均不得分"的，判 `FAIL` |

## 四、承诺函怎么算

- 原文写"需提供承诺函并加盖供应商公章"的条款，只要公司**愿意出**承诺函，通常即可得分。
- 在 `company_profile.json` 的 `declarations` 里如实登记：愿意 = `true`，不愿意 = `false`，未决定 = `null`。
- `true` 且条款本身可承诺 → 判 `PASS`，note 写"需出具承诺函"。
- `false` → 判 `FAIL`（这是真实风险，不许美化成 UNKNOWN）。
- `null` → 判 `UNKNOWN`，missing 写"待公司确认是否出具承诺函"。
- **例外**：条款要求的是**既成事实**（如"平台已运行课程不低于 3000 门"）而不是承诺，那就必须拿证据，承诺函不算数。判断依据：原文写的是"须提供……证明材料"还是"须提供承诺函"。

## 五、信用记录的时效性

失信被执行人、重大税收违法、政府采购严重违法失信名单是**时点数据**，必须现场查询并截图。

- 截图要有查询日期，超过 7 天重查。
- 没查 → 判 `UNKNOWN`，missing 写"未查询信用中国/中国政府采购网"。
- **不得**凭"公司看起来正常"就判 `PASS`。这是出局级的硬门槛。

## 六、中小企业认定

- 以《中小企业划型标准规定》按**所属行业 + 营业收入 + 从业人员**判定，不是公司自己说微型就是微型。
- 本项目所属行业为"软件和信息技术服务业"（从业人员 300 人以下或营业收入 10000 万元以下为中小微）。
- 拿不到营业收入/人数 → `UNKNOWN`。
- 专门面向中小企业采购的项目，这条是硬门槛，判不出来整份报告就是"待定"，不许放行。

## 七、填不出来的正确写法

```
status: UNKNOWN
missing: "缺 2025 年度审计报告（用于确认营业收入与划型）"
note: "公司口头称营收约 800 万，无书面材料，不做采信"
```

而不是：

```
status: PASS   ← 错
note: "公司规模较小，应该符合中小企业"   ← 错
```
