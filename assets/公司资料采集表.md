# 受评公司资料采集表

> 使用方式：把这份表发给被评估的公司（或自己填），填完连同材料扫描件一起放进资料目录。
> **填不出来就空着**，不要"大概是""应该能开"。空着最多被判"资料不足"，填错会被判"不符合"甚至"提供虚假材料"。

## 先说清楚：大部分不用你填

评估方会先用**企查查**把下面这些拉出来，你不用重复提供：

| 企查查能查到 | 对应下表 |
| --- | --- |
| 营业执照信息、成立时间、注册资本、行业、登记状态 | 一（全部） |
| 失信被执行人、严重违法失信、经营异常、行政处罚 | 二（前三项） |
| 软件著作权、专利、商标 | 三 |
| 中标记录 | 四（项目名称与日期） |
| 社保参保人数 | 一（员工人数） |

**下表要你填的，是企查查查不到的部分。**

⚠️ 一个例外：**政府采购严重违法失信名单**在中国政府采购网（ccgp.gov.cn），企查查不覆盖，评估方会单独查——不用你提供，但也别以为"企查查没问题"就等于这项过了。
